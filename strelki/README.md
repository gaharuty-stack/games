# Стрелки: Новогодняя сортировка

HTML5-головоломка для «Игр ВКонтакте». Механика повторяет то, что сейчас растёт в топе ВК («ТапТап Стрелка», «Разбери Стрелочки», «Сортировка Стрелок»): поле со стрелками и сортировка по цвету.

- Нажимаешь на стрелку, и она вылетает с поля, если путь до края свободен.
- Вылетевшая стрелка летит в подарок своего цвета. Если подходящего подарка нет, она ждёт на полке.
- Три стрелки заполняют подарок: он закрывается и улетает.
- Полка заполнилась — проигрыш. Врезался в другую стрелку — минус сердечко (всего их 3).

Вся графика векторная (SVG, нарисована в коде) и растеризуется под экран устройства. Звук синтезируется через WebAudio, файлов нет. Сборка весит ~260 КБ, архив ~125 КБ.

## Запуск

```
npm install          # один раз: ставит сборщик esbuild
npm run serve        # локальный сервер → http://127.0.0.1:8765
```

Полезные параметры адреса:

- `?level=12` — сразу открыть уровень 12;
- `?nodaily` — не показывать подарок дня;
- `?vk_app_id=1` — включить «режим ВК» (кнопки рейтинга и приглашений).

Вне ВК реклама заменена тестовой заглушкой «Реклама (тест)», награда выдаётся.

## Сборка для ВК

```
npm run build
```

Появятся папка `dist/` и архив `strelki-vk.zip`: всё в одном минифицированном `game.js`, без внешних зависимостей. Шрифт Nunito (лицензия OFL) и VK Bridge лежат внутри.

## Публикация в ВКонтакте (чек-лист)

Названия разделов в кабинете разработчика ВК иногда меняются. Сверяйтесь с актуальной документацией на dev.vk.com.

1. Создайте приложение типа «Игра» (HTML5) в кабинете разработчика ВК.
2. Разместите игру одним из двух способов:
   - загрузите содержимое `strelki-vk.zip` на хостинг ВК, если он доступен для вашего приложения;
   - выложите содержимое `dist/` на свой HTTPS-хостинг и укажите адрес в настройках приложения.
3. В разделе монетизации включите рекламу: межстраничную и с вознаграждением. Игра уже вызывает `VKWebAppShowNativeAds` с форматами `interstitial` и `reward`.
4. Включите таблицу рекордов по уровням. Кнопка с кубком в меню вызывает `VKWebAppShowLeaderBoardBox`.
5. Загрузите промо-материалы из папки `promo/`: иконку, баннер и скриншоты. Перед загрузкой проверьте требуемые размеры в кабинете. При необходимости картинки перерисовываются через `tools/promo.html`.
6. Сдайте игру на модерацию. Выпустить её стоит до начала декабря: новогодний спрос растёт уже сейчас.

## Монетизация (уже встроена)

**Реклама с вознаграждением** — игрок смотрит её сам, ради выгоды:

- «Забрать x2» — удвоить монеты за пройденный уровень;
- «Продолжить» после проигрыша: +1 место на полке или восстановление сердечек (до 3 раз за уровень);
- 6-е место на полке (замочек с видео-значком);
- бесплатный бонус, когда бонусы закончились.

**Межстраничная реклама** включается начиная с 6-го уровня, при переходе между уровнями и не чаще раза в 90 секунд. Первую сессию она не портит. Настраивается в `js/main.js` → `maybeInterstitial`.

**Монеты** тратятся на бонусы (подсказка 80, снежок 120, магнит 150) и на продолжение (150). За уровень даётся 20 монет, за сложный — 40. Монет не хватает ровно настолько, чтобы реклама с вознаграждением оставалась привлекательной.

## Удержание

- Подарок дня: 7-дневная серия, на 7-й день суперприз.
- Ёлка в меню: за каждый уровень на неё прилетает игрушка (40 штук), на 10-м уровне — звезда на макушку.
- Пила сложности: каждый 5-й уровень «СЛОЖНЫЙ», после него передышка.
- Предложение добавить игру в избранное (с 4-го уровня, один раз).
- Облачное сохранение через VK Storage: прогресс не теряется при смене устройства.

## Уровни

- 300 уровней заранее откалиброваны ботом (`js/levels-data.js`). Дальше уровни бесконечно перемешиваются: зеркалятся и меняют цвета.
- Каждый уровень гарантированно решаем: генератор строит его в обратном порядке. Проверено на 1500 уровнях.
- Целевая проходимость для «казуального» бота задаётся в `tools/bot.mjs` → `targetWin`. Изменили кривую — перегенерируйте уровни: `npm run levels`.

## Структура

| Файл | Что внутри |
|---|---|
| `js/main.js` | цикл, масштаб (портрет и ландшафт), ввод, переходы, реклама |
| `js/game.js` | игровая сцена: поле, коробки, полка, бонусы, обучение |
| `js/menu.js` | меню с ёлкой и снеговиком |
| `js/popups.js` | окна: победа, поражение, пауза, бонусы, подарок дня |
| `js/art.js` | вся графика (SVG-спрайты) |
| `js/bg.js` | фон: небо, сияние, деревня, снег |
| `js/level.js` | генератор и проверка уровней |
| `js/audio.js` | синтез звуков и музыки («Jingle Bells» — общественное достояние) |
| `js/vk.js` | VK Bridge: реклама, хранилище, рейтинг, избранное |
| `tools/` | генерация уровней, бот-тестер, сборка, промо |

## Что дальше для заработка

1. **Покупки за голоса** (`VKWebAppShowOrderBox`): наборы монет и «без рекламы». Нужен небольшой сервер для подтверждения платежей ВК.
2. **Уведомления** («подарок дня ждёт»). Тоже нужен сервер, но это сильно поднимает возвраты.
3. **Аналитика**: где игроки бросают уровни. По ней правится `targetWin`.
4. **После праздников** — сменить оформление на зимнее/весеннее, механика остаётся.
